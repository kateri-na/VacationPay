## При отправке запроса по адресу http://localhost:8080/calculate возвращается рассчитанное количество отпускных:
# Принимаемые параметры в get запросе:

* средняя зарплата за 12 месяцев
* количество дней отпуска
* дата начала отпуска
* дата окончания отпуска

> При введении точных дней ухода в отпуск, проводится рассчет отпускных с учётом праздников
